# CTA-PRE-009 acceptance checklist

- Quantitative questionnaire versions are project-scoped and published explicitly.
- Only bounded quantitative question types are accepted; free-text qualitative questions are rejected.
- Questions carry stable codes, metric keys, scale definitions and options.
- Studies use published questionnaires and project-owned creative assets.
- Respondent identifiers are stored only as study-scoped SHA-256 hashes.
- Human, imported and synthetic response sources are labelled.
- Synthetic responses require provenance and are explicitly marked as not real people.
- Deterministic simulation supports fixed seeds and declared creative effects.
- Results aggregate counts, numeric summaries and categorical distributions per creative.
- Results state that proxy/synthetic evidence is not observed campaign lift or CTR.
- API, audit, migration, documentation and executable tests are included.
