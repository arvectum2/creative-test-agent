# Creative Test Agent 0.1.0-rc1

## Status

Release candidate for controlled local/on-premise evaluation. The application has a complete synthetic demonstration and controlled-pilot workflow, but it is not a public production release and has no production SLA.

## Included

- client/project workspaces and project history;
- text, image and PDF creative intake;
- brand, audience, rubric and brandbook context;
- local LLM/VLM pipeline with fail-closed structured output;
- batch and A/B creative comparison;
- reports and real local DOCX/PPTX/PDF-ready exports;
- finding-level expert review, two-reviewer adjudication and calibration dashboard;
- controlled-pilot intake, immutable blind runs and outcome separation;
- audit log, prompt tracing, role-based access and local session authentication;
- SQLite persistence, migrations, backup and verified restore;
- frozen Mac mini M4 Pro / 24 GB production model profile;
- deterministic on-premise release bundle, SBOM and clean-install verification.

## Closed-loop guarantees

- cloud LLM fallback is disabled;
- production model endpoints are loopback-only;
- client materials and results remain in local storage;
- no telemetry or external data transmission is required;
- invalid model output fails closed or falls back to explicitly marked local deterministic output;
- frozen model identity, revision and integrity hashes are verified before production-model use.

## Release preparation

Build and validate the deterministic on-premise artifact:

```bash
python scripts/cta_release_prep_001.py --project-root . build \
  --source-revision "$(git rev-parse HEAD)"

python scripts/cta_release_prep_001.py --project-root . validate \
  --bundle data/release/cta-release-prep-001/creative-test-agent-onprem-0.1.0-rc1.zip
```

Run clean-machine synthetic installation and executable rollback rehearsal:

```bash
python scripts/cta_release_prep_001_clean_install.py \
  --bundle data/release/cta-release-prep-001/creative-test-agent-onprem-0.1.0-rc1.zip
```

## Frozen local model profile

Accepted target profile:

- hardware: Mac mini Apple M4 Pro, 24 GB unified memory;
- VLM: `mlx-community/Qwen3-VL-4B-Instruct-4bit`;
- LLM: `mlx-community/Qwen3.5-4B-MLX-4bit`;
- VLM endpoint: `127.0.0.1:8091`;
- LLM endpoint: `127.0.0.1:8093`;
- profile: `config/model_profiles/production/cta_model_001.mac_mini_m4pro_24gb.frozen.json`.

Model weights are installed separately and are not distributed in the release bundle.

## Known limitations

- application dependencies are represented in the SBOM by declared version specifications; frozen model runtime dependencies include exact accepted pins where available;
- SQLite is intended for a single-team pilot, not high-concurrency multi-tenant production;
- no SSO, MFA, automatic password reset or enterprise identity provider integration;
- no public ingress, automated HTTPS/domain configuration or Kubernetes orchestration;
- video analysis is outside the current release contour;
- actual client-infrastructure installation is a separate `CTA-DEPLOY-001` task;
- real-client controlled pilot and methodology validation remain separate from synthetic acceptance.

## Claim boundary

This release candidate demonstrates reproducible packaging, local execution and synthetic workflow integration. It does not establish validated production accuracy, causal brand lift, numeric uplift prediction, regulatory approval or production readiness for arbitrary infrastructure.
