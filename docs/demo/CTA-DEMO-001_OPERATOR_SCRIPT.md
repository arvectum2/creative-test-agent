# CTA-DEMO-001 — Operator script

Target duration: 8–12 minutes. The operator should use one complete contrast case first and then one limitation case.

## Before the call

1. Start the application in local-only mode and confirm the status banner shows closed-loop ON and cloud LLMs blocked.
2. Open the Ozon showcase project and confirm campaign evidence loads.
3. Prefer a case with: accepted creative linkage, real preview, canonical visual evidence, completed diagnostic and observed CG/TG rows.
4. Generate report v2 once only if response time could interrupt the meeting; otherwise generate it live.
5. Keep a limitation case ready: multi-asset, rejected platform link or missing values.

## Canonical talk track

### 1. Showcase project

Show the project-level context and say: “This is one local evidence workspace. Files, normalization, diagnostics and reports remain inside the closed contour.”

Do not claim that the presence of data proves quality or accuracy.

### 2. Campaign selection

Select the campaign and state its case ID, platform, period and linkage limitations before discussing any result.

Recommended phrase: “First we establish what evidence belongs to this campaign and at what confidence.”

### 3. Original creative

Open the preview. Point to the original filename, inferred platform, linkage status and confidence.

Stop if the file does not open or the selected asset is rejected for the campaign set.

### 4. Visual extraction

Show provider, extraction confidence, evidence confidence, completeness, fingerprint and observation-level references. Read one OCR/summary observation and one structural observation.

Recommended phrase: “A missing field means unassessed, not visually absent. An assessed absence must be explicit.”

### 5. Funnel diagnostics

Show overall score, effective recommendation, scorecard, findings and risks. State that this is an asset-level diagnostic output.

Do not rename manual review, abstention or limited evidence as a positive or negative verdict.

### 6. CG/TG comparison

Show the observed campaign-level rows beside diagnostics. Use “descriptive difference” rather than “uplift caused by the creative”.

Required phrase: “The system does not attribute campaign outcomes to one asset and does not generate a numeric performance prediction.”

### 7. Report

Generate report v2. Show report ID, release status and manifest SHA-256. Download the format requested by the client; keep evidence JSON and XLSX for audit.

State that expert assessments remain `not_reviewed` until supplied by a real reviewer.

## Limitation case

After the complete case, switch to one limited case and show that the product does not hide:

- one-to-many or uncertain asset linkage;
- a rejected platform mismatch;
- missing TG or other outcome values;
- missing visual extraction;
- missing completed diagnostic.

## Forbidden claims

- “The model predicts brand lift.”
- “This creative caused the observed difference.”
- “The score is validated accuracy.”
- “Missing means absent.”
- “The synthetic acceptance bundle validates the real client data.”
